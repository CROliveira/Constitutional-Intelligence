# IMPACT™ — Information Architecture for Decision-Grade Data

## What it is

IMPACT is an information architecture that structures data so every consequential decision is traceable to evidence: where the data came from, how it was transformed, who is accountable for it, and what rights or constraints govern its use. It treats information architecture as constitutional infrastructure — the layer that makes trustworthy AI possible, because no model is more legitimate than the data it stands on.

## When to use it

- Before building dashboards, AI pilots, or automated decision systems.
- When data is fragmented across units and no one can answer "where did this number come from?"
- When a decision needs an audit trail — for oversight bodies, courts, or the public record.
- When legacy systems and electoral changeover threaten continuity of evidence.

## Three-step application

1. **Map decisions to information needs.** List the decisions the system must support, then work backward: what facts must be true, current, and provable for each decision to be defensible?
2. **Qualify every source.** For each source, record lineage, quality, refresh cadence, ownership, and any legal or rights-based constraints on use. If a source can't be qualified, it can't support a consequential decision.
3. **Architect the flow with checkpoints.** Design capture → curation → consumption as a governed pipeline: validation at capture, standards at curation, access controls and logging at consumption. Each checkpoint is a named accountability.
