# Constitutional Intelligence™ — Companion Repository

The public companion to ***Constitutional Intelligence™: A Decision Architecture for Trustworthy AI Governance*** (FriesenPress, 2026, ISBN 978-1-03-835671-0) by Celio Oliveira.

The book gives government executives a practical decision architecture for implementing AI within Westminster parliamentary systems — accountable, human-centred, and built to survive electoral changeover. This repository distills its four frameworks into one-page explainers and a reusable worksheet.

**Get the book:** [fedethics.ca/book-hub](https://fedethics.ca/book-hub/) · [Amazon and all major bookstores](https://www.amazon.com/s?k=9781038356710)

## Framework map

| Framework | What it answers | |
|---|---|---|
| [IMPACT™](frameworks/IMPACT.md) | Information architecture for decision-grade data | *How do we make data worthy of the decisions it informs?* |
| [DECIDE-PLUS™](frameworks/DECIDE-PLUS.md) | Decision methodology for AI-era leaders | *How do we make high-stakes technical decisions constitutionally?* |
| [FIVE-LAYER™](frameworks/FIVE-LAYER.md) | Architecture for trustworthy AI systems | *How do we coordinate AI implementation across the whole institution?* |
| [CHARTER RIGHTS DECISION TREE™](frameworks/CHARTER-RIGHTS-DECISION-TREE.md) | Rights-aware decision design | *Does this decision respect the Canadian Charter of Rights and Freedoms?* |

Also in this repo: a [fill-in DECIDE-PLUS worksheet](worksheets/decide-plus-worksheet.md) you can copy for your own decisions.

## How to use this repo

1. Start with the framework that matches your current problem (see the map above).
2. Each explainer gives you the definition, when to use it, and a three-step application.
3. Go deeper in the book — these pages are overviews; the authoritative treatment, case studies, and full methods are in *Constitutional Intelligence*.
